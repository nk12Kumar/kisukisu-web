# KisuKisu — web build

This repository contains the built web client, served at
**https://nk12kumar.github.io/kisukisu-web/** — nothing else. There is no source here and
nothing to configure.

Add it to your home screen (Safari → Share → Add to Home Screen) and it opens as a standalone
app.

**It is a preview.** The build has no server behind it yet: you can open a table, copy its code,
write messages and end it, but nothing leaves the device and no second person can join. The
interface says so on the main screen rather than implying otherwise.

- Project overview and design notes: [kisukisu-project](https://github.com/nk12Kumar/kisukisu-project)
- What is and is not encrypted: [docs/security.md](https://github.com/nk12Kumar/kisukisu-project/blob/main/docs/security.md)

The build is produced from a private source repository; this repo only ever receives the
compiled output.
